# Plan: Elves v2.22.0 full Linear backlog resolution

## Mission

Resolve every remaining open Linear issue on project **elves** (Aigora) in one finite Elves run,
ship a **Claude Code / Codex parity** release as **v2.22.0**, land with **Fugu review plus
independent agent review** then a regular merge commit, and deliver an **X announcement draft in
chat** (same account as last Elves release; do not auto-post). Observable done: Linear Todos closed
with evidence, CHANGELOG/guide/docs current for 2.22.0, version bumped post-merge, announcement text
ready for the user to post.

## Scope

### In scope

- All open Linear project `elves` issues as of staging (not AIG-313 Done): **AIG-238, 239, 277–283,
  310–312, 369, 411–425**.
- GitHub twins #198–#233 where they map to those issues; close or comment in lockstep when Linear
  closes.

  baseline; finish any residual review/CI for that surface as part of terminal readiness.
- Cross-family / any-catalog-model worker handoffs with prewalk and caching for efficiency under
  the existing safety kernel (AIG-238).
- Compaction stewardship **P3 and P4** (AIG-280).
- Parallelves Phase 2 staging validation **and** runtime lane supervision (AIG-281, AIG-282).
- Structural debt next-wave tracker AIG-279: clear the tracked next-wave items (or equivalent
  concrete children) so the umbrella can close honestly.
- Planning / Command Center harvest epic AIG-411–425.
- Remotion summary videos (AIG-369).
- Token-efficiency assessment and tool-output compact layer (AIG-283, AIG-310) to a shippable
  or explicit assessment-close bar defined in batch acceptance.
- Docs: SKILL, AGENTS, README, guide, references, CHANGELOG, consistency pins, Claude aliases.
- Terminal gates: full suite (or project full gate), Fugu review of the cumulative diff, independent
  agent review, Claude/Codex parity check, then merge-commit-on-green.
- Post-merge: version **2.22.0** across skill surfaces, and X announcement **text in chat only**.

### Out of scope

- Auto-posting to X (draft text only).
- Squash merges.
- Weakening the thin safety kernel, protected-ref rules, or inventing remaining quota.
- Replacing native default workers with a paid-only path; any-model handoff is opt-in/user-specified.
- Unrelated product repos; this run is `aigorahub/elves` only.
- Mass-closing issues without ship evidence or an explicit product “won’t do” recorded on the issue.

## Non-negotiables

- User authorized **merge after Fugu review and independent agent review** are clean.
- **Grok 4.5 high** is main driver and implementer (host-native); no silent downgrade.
- **Claude Code and Codex parity** for every new operator surface.
- **Do not stop** until all in-scope Linear issues are resolved or a true Hard Stop blocker.
- Confidence trailers on batch Close commits; mid-run impact path; terminal full suite + deferred
  hygiene drain.

- **Risk:** high (routing, isolation, Parallelves runtime, handoff/prewalk).
- **Trust:** trusted host-native implementation on the feature branch.
- **Landing outcome:** complete_and_merge after readiness + dual review.
