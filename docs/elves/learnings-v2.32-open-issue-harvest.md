# Learnings — v2.32 open-issue harvest

Run-scoped lessons. Promote durable ones to `docs/elves/learnings.md` at terminal readiness.

- 2026-08-20 — Five open issues carried maintainer comments saying "close on merge" for a PR that
  merged thirteen days earlier. Verify a "close on merge" claim against the current default-branch
  tree before closing, then close it. Neither half is optional: the merge comment alone is not
  proof, and leaving a verified-fixed issue open costs every later triage pass.
